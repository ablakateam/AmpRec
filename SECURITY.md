# Security Policy

## Supported versions

Security fixes are provided for the latest AmpRec release.

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Security** tab and select **Report a vulnerability** to start a private security advisory with the maintainers.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Please allow reasonable time for investigation and coordinated disclosure.

AmpRec binaries are currently unsigned. Always download releases from the official repository and verify the published SHA-256 checksums.
